# Changelog

All notable changes to Notion Obsidian are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/).

## [1.1.0] - 2026-10-19

### Added

- A "Settings window font size" slider in Style Settings. It sets the text size of the Settings
  window separately from the sidebar and tabs, and it defaults to 0.95rem.

### Changed

- The "UI font size" slider no longer affects the Settings window.

## [1.0.0] - 2026-10-19

### Added

- First release as Notion Obsidian, forked from Obsidianotion v1.1.39 by Diego Eis.
- Fira Sans, Source Sans 3, Nunito Sans and Fira Code embedded in `theme.css` as WOFF2, with
  their SIL Open Font License 1.1 texts.

### Changed

- The Style Settings defaults are a 1280px body width, Fira Sans, a 0.825rem interface font, and
  H1 to H4 at 1.8, 1.4, 1.3 and 1.2rem.
- The "Small interface font" toggle no longer changes the body width.
